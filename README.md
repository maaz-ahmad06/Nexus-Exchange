# 🚀 Nexus Exchange — Cryptocurrency Exchange Platform

A premium, state-of-the-art cryptocurrency landing page and trading dashboard mockup. Designed with rich glassmorphism aesthetics, neon cyber gradients, smooth micro-animations, and 100% responsive fluid layouts without horizontal scrollbars.

---

## ✨ Features

- ⏳ **2.5s Custom Preloader**: Sleek vector-logo animation with matching percentage loader bar and counter.
- 📈 **Live Market Tickers**: Dynamic simulated pricing engine updates rates randomly by ±0.6% every 3 seconds. Updates include color highlights and flashes showing price direction.
- 📊 **Dynamic Sparkline Charts**: Inline vector polyline graphs generated in real time as price updates occur.
- 💱 **Interactive Swap Widget**: Fully operational fiat-to-crypto and crypto-to-crypto price conversion with swapping rotation.
- 📱 **100% Responsive Design**: Clean layouts using CSS Grid and Flexbox optimized for standard Mobile, Tablet, Laptop, and Ultra-wide monitor views.
- 🔒 **No Overflow scrolls**: Complete structural constraints prevents ugly horizontal scrollbars across all screen widths.
- 🌀 **Visual Glow Orbs**: Ambient blurred gradients positioned dynamically in the background for a modern fintech look.

---

## 🛠️ Built With

*   **HTML5** — Semantic content structure and SEO schema configuration.
*   **CSS3** — Custom styling systems, responsive layout media rules, scrollbar adjustments, and keyframe animations.
*   **ES6+ JavaScript** — Event routing, ticker rates simulation, and IntersectionObserver scroll anchors.

## 🚀 Quick Start / How to Run

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/yourusername/cryptocurrency-exchange.git
    cd cryptocurrency-exchange
    ```

2.  **Open in Browser**:
    Simply open the `index.html` file inside any modern browser (Chrome, Safari, Firefox, Edge).
    ```bash
    # On Windows:
    start index.html
    
    # On Mac:
    open index.html
    ```
